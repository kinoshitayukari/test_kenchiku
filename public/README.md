# public ディレクトリの使い方

このプロジェクトでは、ブラウザから直接アップロードする画像や、ビルド処理を経ずに配信したい静的ファイルを `public/` に配置します。

## 画像を追加する手順（GitHub Web UI）
1. GitHub で本リポジトリを開き、`public/` ディレクトリに移動します。
2. 右上の **Add file > Upload files** をクリックします。
3. 画像をドラッグ＆ドロップするかファイル選択し、`Commit changes` を押します。
4. 必要に応じてサブフォルダ（例: `public/images/`）を作成して整理してください。

## コードから参照する方法
- ルート相対パスで参照できます。例: `src` や `pages` から `/images/example.png`。
- Vite の場合、`public/` 配下はビルド時にそのまま出力されるのでインポート不要です。

## ベストプラクティス
- ファイル名は半角英数・ハイフンで統一するとパスが扱いやすくなります。
- 大きな画像は適度に圧縮し、必要に応じて `webp` 形式も検討してください。
- 不要になった画像は削除して、リポジトリをクリーンに保ってください。
